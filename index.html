The part you can have tonight

This is Palette.

Palette is the plug-and-play app for trying the system out, and it is free. Give it a folder and it lists what is there without opening a single file. You grant it one folder at a time, and nothing is read until you do. It never goes looking on its own. That is how you find out this is real before you talk to anybody. What we build with you is a different thing: your own application, shaped to your business, and yours to keep.

What happens when you open it

Nothing to set up first. The empty screen offers one button, Try it with sample notes, which drops four example notes into the app’s own folder and opens the file. The notes are invented for the demo. The pipeline that turns them into a document is the same one that would run on your own material.

  1. You tell it something in your own words. Type it, or hold the microphone.
  2. It proposes structured facts. You accept or correct each one.
  3. It produces a brief assembled only from the facts you accepted.
  4. Click any claim to land on the exact sentence in the source it came from.

A side panel reports what it has and has not got, including when it has no model and no mailbox connected. A system that will tell you it is empty is a system that cannot quietly make things up. For the same reason it does not write prose for you: the document is a template filled with the facts you accepted, and nothing else.
