## What is Mission Canvas?

AI governance computed by a deterministic stage before any model is invoked. Classification, boundary enforcement, and routing are fixed-function — zero model calls, microseconds of CPU. The model never runs ungoverned.

Three products ship from this architecture: Mission Canvas (professional governance), Lingua Viva (education), and Tropical AI (IT operations).
