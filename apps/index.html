After it downloads

  • Mac — open the .dmg and drag the app into Applications. Mission Canvas is signed and notarized. If macOS still says the app can't be verified, right-click it and choose Open.
  • Windows — run the -Setup.exe installer. It is not yet code-signed, so SmartScreen shows "Windows protected your PC": click More info, then Run anyway.
  • Linux — the .AppImage downloads without permission to run, so double-clicking does nothing. In a terminal: chmod +x ~/Downloads/MissionCanvas.AppImage && ~/Downloads/MissionCanvas.AppImage (same for the other apps, with their file name). On Ubuntu 22.04 or newer, first sudo apt install libfuse2.
